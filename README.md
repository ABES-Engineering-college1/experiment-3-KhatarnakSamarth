### Create a Web Page for College Timetable
Use of Tables with Rowspan, Colspan, Headers, Captions, and Nested Tables.

## 🎯 Objectives
1. To design a college timetable webpage using HTML tables.

3. To use table headers (`<th>`), captions (`<caption>`), and formatting for readability.

---

## 📚 Theory

### 1. Table (`<table>`)
Arranges data in rows and columns.
### 2. Rowspan
Merges a cell vertically across rows.  
Example: `<td rowspan="2">Lab</td>`
### 3. Colspan
Merges a cell horizontally across columns.  
Example: `<td colspan="3">Break</td>`
### 4. Header (`<th>`)
Displays header cells in bold and centered.
### 5. Caption (`<caption>`)
Defines the title of the table.
### 6. Nested Table
A table placed inside another table cell.
